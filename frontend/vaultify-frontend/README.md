# Vaultify – Frontend

React + TypeScript + Vite frontend for Vaultify, packaged as an Electron desktop app.

See the [root README](../../README.md) for full project documentation and getting started guide.

## Dev commands

| Command | Description |
|---|---|
| `npm run dev` | Start Vite dev server (browser) |
| `npm run electron:dev` | Start as Electron desktop app |
| `npm run electron:build` | Build Windows installer |
| `npm run build` | Production web build |
